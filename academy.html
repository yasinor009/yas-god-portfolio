A SMALL EXAMPLE

Build a useful function.

A function gives a clear name to reusable behavior. This example computes a stock total from a list.

def total_units(items):
    return sum(item["quantity"] for item in items)

stock = [{"quantity": 42}, {"quantity": 76}]
print(total_units(stock))  # 118
